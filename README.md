# AI-генератор контента для социальных сетей с функцией автопостинга

Приложение автоматизирует подготовку и распространение контента для SMM. Оно помогает составлять контент-планы с помощью AI, поддерживать регулярный график публикаций и управлять постами для разных площадок из одного дашборда.

## Возможности

- **Генерация контент-плана.** Выберите нишу, тон, площадку и период от 1 до 30 дней. OpenAI Chat Completions создаёт по одному черновику на день. При отсутствии ключа, сбое сети или исчерпании квоты приложение создаёт пять разных черновиков по локальным шаблонам. Предложенные даты становятся расписанием после подтверждения в дашборде.
- **Управление постами.** Дашборд Flask показывает черновики, запланированные и опубликованные посты, а также ошибки. Посты можно редактировать, удалять, планировать и отправлять сразу. После сбоя можно посмотреть причину и повторить отправку.
- **Отложенная публикация.** APScheduler каждые 30 секунд проверяет сохранённое в SQLite расписание и обрабатывает посты, время которых наступило. Даты в интерфейсе указаны в UTC. Планировщик работает, пока запущен `main.py`, и подхватывает просроченные посты при следующем старте.

### Площадки

- **Telegram · реальная публикация.** Приложение вызывает метод `sendMessage` Telegram Bot API и отправляет текст в указанный канал. Сообщение передаётся с `parse_mode=HTML`, а специальные символы пользовательского текста экранируются.
- **ВКонтакте · реальная публикация или имитация.** При наличии токена и ID сообщества приложение отправляет текст на стену группы через `vk_api` и метод `wall.post`. Если один из параметров пуст, приложение имитирует успешную отправку и отмечает её в журнале.
- **TenChat · экспорт в песочнице.** Генератор готовит деловой текст по схеме «Проблема → Решение → Вывод» и добавляет тематические хэштеги. По расписанию или по кнопке **«Экспортировать сейчас»** приложение сохраняет отформатированный текст в SQLite и записывает результат в журнал. Готовый пост можно скопировать из блока **«Текст для TenChat»** и разместить вручную.

## Технологический стек

- **Python 3.10+**, **Flask**, шаблоны **Jinja** и стили **Tailwind CSS** через CDN.
- **SQLite** и **SQLAlchemy** для хранения постов, расписания и результатов отправки.
- **APScheduler** для фоновой обработки очереди.
- **OpenAI SDK** для генерации и **Pydantic** для проверки настроек и структуры ответов.
- **requests** для прямого вызова Telegram Bot API и **vk_api** для работы с ВКонтакте. **python-telegram-bot** указан в зависимостях, а **httpx** устанавливается вместе с OpenAI SDK.
- **python-dotenv** для загрузки переменных из `.env`.

## Локальная установка

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/alex-hash986/social-ai-autoposter.git
cd social-ai-autoposter
```

### 2. Создайте окружение и установите зависимости

**Windows · PowerShell**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

**Linux · Bash**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

### 3. Настройте `.env`

Откройте `.env` в корне проекта. Пустые поля можно оставить для локальной проверки генерации и экспорта в TenChat.

```dotenv
# Flask
FLASK_DEBUG=0
SECRET_KEY=

# OpenAI
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini

# Telegram
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHANNEL_ID=

# ВКонтакте
VK_ACCESS_TOKEN=
VK_GROUP_ID=
```

- `FLASK_DEBUG` управляет режимом отладки Flask. Для обычного локального запуска используйте `0`. Отдельная переменная `FLASK` приложению не нужна. Адрес и порт заданы в `main.py`.
- `SECRET_KEY` используется для подписи сессий Flask. Если поле пустое, при каждом запуске создаётся новый ключ. Чтобы сохранить сессии между запусками, запишите в `.env` значение, полученное командой `python -c "import secrets; print(secrets.token_hex(32))"`.
- `OPENAI_API_KEY` включает генерацию через OpenAI. `OPENAI_MODEL` задаёт модель со структурированным выводом. По умолчанию используется `gpt-4o-mini`.
- `TELEGRAM_BOT_TOKEN` — токен собственного бота. В `TELEGRAM_CHANNEL_ID` укажите имя канала вида `@my_channel` или его числовой ID вида `-1001234567890`. Добавьте бота в канал с правом публикации сообщений.
- `VK_ACCESS_TOKEN` — токен с правом публикации от имени сообщества. В `VK_GROUP_ID` укажите числовой ID своей группы, например `123456789`.

### 4. Запустите приложение

```bash
python main.py
```

При первом запуске приложение создаст `social_poster.db` в корне проекта и запустит планировщик. Дашборд будет доступен на [http://127.0.0.1:5000](http://127.0.0.1:5000).

Для пробного запуска откройте **«Создать контент-план»**, выберите TenChat и заполните форму. Затем нажмите **«Экспортировать сейчас»** на карточке черновика и раскройте **«Текст для TenChat»**.

## Безопасность

- Используйте только собственные аккаунты, ботов, каналы и сообщества, которыми вы управляете.
- Храните токены и `SECRET_KEY` в локальном `.env`. В репозиторий добавляйте только `.env.example` с пустыми значениями секретов. `.gitignore` исключает `.env` и файлы SQLite с содержимым постов.
- Дашборд запускается на локальном сервере разработки Flask без входа по логину. Используйте его на `127.0.0.1`.
